# Реестр отключённых элементов

Документ фиксирует все поля, модули, кнопки и строки интерфейса, которые были
скрыты или отключены в ERPNext. Перед разработкой новой функциональности —
сверяться с этим документом: возможно, нужное уже есть в системе и просто отключено.

**Правило:** любое изменение видимости полей через Property Setter или Custom Field
обязательно отражается в этом документе.

## Opportunity

| Поле | Что даёт если включить | Причина отключения | Дата |
|------|------------------------|--------------------|------|
| `opportunity_type` | Классификация сделок по типу: Sales / Support / Maintenance | Все сделки одного типа. **Важно:** поле скрыто, но дефолтное значение "Продажи" должно существовать в справочнике Opportunity Type — создаётся скриптом `crm_setup.py` | 2026-06-11 |
| `expected_closing` | Дата закрытия — используется в отчёте Sales Pipeline и прогнозах выручки | Убрана обязательность, скрыта — мешала при создании | 2026-06-11 |
| `probability` | Вероятность закрытия % — используется во взвешенном прогнозе выручки | Субъективный показатель, не используем | 2026-06-11 |
| `campaign` | Привязка сделки к маркетинговой кампании, аналитика ROI по кампаниям | Нет маркетинговых кампаний | 2026-06-11 |
| `source` | Источник лида: холодный звонок / сайт / реферал — аналитика каналов привлечения | Не отслеживаем источники на этом этапе | 2026-06-11 |
| `contact_display` | Авто-отображение отформатированного имени контакта | Дублирует contact_person | 2026-06-11 |
| `customer_address` | Адрес клиента — нужен для доставки и печатных документов | Не нужен на этапе сделки | 2026-06-11 |
| `address_display` | Отформатированный адрес | Дублирует customer_address | 2026-06-11 |
| `items` (секция) | Таблица позиций — основа для создания КП прямо из сделки | Загромождает форму, нужна только на этапе КП | 2026-06-11 |
| `with_items` | Чекбокс включения таблицы позиций | Связан с секцией items | 2026-06-11 |
| `competitors` (секция) | Фиксация конкурентов по сделке — аналитика win/loss по конкурентам | Не ведём анализ конкурентов | 2026-06-11 |
| `terms` (секция) | Условия договора — переносятся в КП и счёт автоматически | Не нужны на этапе сделки | 2026-06-11 |

## CRM Workspace — боковое меню

Sidebar определяется в `Workspace Sidebar` DocType (источник: `erpnext/workspace_sidebar/crm.json`).
Изменения применяются скриптом `crm_setup.py`, функция `cleanup_crm_workspace()`.

| Элемент | Что даёт если включить | Причина отключения | Дата |
|---------|------------------------|--------------------|------|
| Отчёты | Встроенные CRM-отчёты: воронка, активность лидов, конверсия | Не используем на текущем этапе | 2026-06-11 |
| Техническое обслуживание → График обслуживания | Планирование регламентных работ по клиентам | Не релевантно для металлопроизводства | 2026-06-11 |
| Техническое обслуживание → Визит обслуживания | Фиксация выездов на обслуживание | Не релевантно для металлопроизводства | 2026-06-11 |
| Техническое обслуживание → Претензия по гарантии | Гарантийные обращения клиентов | Не релевантно на текущем этапе | 2026-06-11 |
| Воронка продаж → Контракт | Управление договорами прямо из CRM | Не используем на текущем этапе | 2026-06-11 |
| Воронка продаж → Встреча | Запись встреч с клиентами, интеграция с календарём | Не используем на текущем этапе | 2026-06-11 |
| Воронка продаж → Коммуникация | Лог всех коммуникаций по сделкам | Не используем на текущем этапе | 2026-06-11 |
| Кампания (весь раздел) | Email/SMS маркетинг, рассылки, группы контактов | Нет маркетинговых активностей | 2026-06-11 |

### Lead — кастомные поля

| fieldname | Тип | Метка | Примечание |
|-----------|-----|-------|------------|
| `mw_full_name` | Data | ФИО (reqd) | Левая колонка блока «Контакт»; синхронизируется в `first_name` через Client Script |
| `mw_job_title` | Data | Должность | Левая колонка блока «Контакт»; синхронизируется в `job_title` |
| `mw_cb_contact` | Column Break | — | Разделитель: ФИО+Должность ‖ Email+Мобильный+Телефон |
| `mw_estimated_volume` | Float | Объём (тонн) | Левая колонка «Организация и запрос» |
| `mw_desired_delivery_date` | Date | Желаемая дата поставки | Левая колонка |
| `mw_drawing_status` | Select | Наличие чертежей | Левая колонка; варианты: Есть готовые / Нужна разработка / Частично |
| `mw_ai_comment` | Text | AI-комментарий | Левая колонка; read_only=1, заполняется AI |
| `mw_note` | Small Text | Примечание | Левая колонка |
| `mw_cb_org` | Column Break | — | Разделитель: левая колонка ‖ Источник+Город+Регион |
| `mw_source` | Link → UTM Source | Источник | Правая колонка «Организация и запрос» |
| `mw_city` | Data | Город | Правая колонка |
| `mw_state` | Data | Регион | Правая колонка |

### Client Script `Lead-Form`

Синхронизирует кастомные поля со стандартными (нужно для конвертации лида в контакт):
- `mw_full_name` → `first_name`
- `mw_job_title` → `job_title`
