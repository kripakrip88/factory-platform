# Тесты приёма/отправки почты (mail.ru) — приёмка

После фикса доставки (ветка `feature/email-delivery-fix`, см. `email_delivery.py`).
Выполнить вживую. Критерий отправки — НЕ «отправилось», а «дошло».

## Задача 2 — Отправка доходит (главное)
- [ ] 1. Отправить из ERPNext письмо на внешний тестовый ящик (gmail/др., не pmkpark).
      Ожидаем: письмо пришло получателю (проверить и «Спам»); From = `pmkpark@mail.ru`.
- [ ] 2. Email Queue: новое письмо в статусе **Sent**, не Error.
      (Старые 2 письма с ошибкой `550 not local sender` — до фикса, игнор.)

## Задача 3 — Копия в «Отправленных» mail.ru
- [ ] 3. Веб-почта mail.ru → «Отправленные»: письмо из теста №1 там есть.
- [ ] 4. ERPNext инбокс → «Отправленные»: письмо видно.

## Задача 1 — Приём всех входящих
- [ ] 5. Прислать на `pmkpark@mail.ru` письмо с другого ящика → СРАЗУ открыть его в
      веб-почте mail.ru (сделать прочитанным) → подождать ≤10 мин (или ручной синк).
      Ожидаем: письмо всё равно подтянулось в ERPNext (раньше такие пропускались —
      причина была режим UNSEEN, теперь ALL).
- [ ] 6. (по желанию) Сравнить число писем за день в mail.ru и в ERPNext — расхождений нет.

## Регрессия
- [ ] 7. Инбокс/полки/папки/классификатор работают как раньше.
- [ ] 8. Тема цела (горизонтальное меню, тёмная/светлая).

## Если что-то не так
- Отправка даёт 550/ошибку auth → нужен пароль приложения mail.ru (создаёт Антон:
  Настройки mail.ru → пароли для внешних приложений → вписать в Email Account). В код/чат не пишем.
- Нет копии в «Отправленных» mail.ru → имя папки не «Sent» → поправить `sent_folder_name`.
- Входящие всё ещё неполные → письма падают фильтром mail.ru в другую папку (не INBOX) →
  добавить эту папку в синк аккаунта (IMAP Folder).
