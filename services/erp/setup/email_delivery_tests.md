# Тесты приёма/отправки почты (mail.ru) — приёмка

После применения `email_delivery.py` (ветка `feature/email-list-fix`). Выполнить
вживую; критерий отправки — не «отправилось», а «дошло».

## Применение (прод, осознанно, после бэкапа)
```
bench --site erp.localhost execute setup.email_delivery.execute
```
Идемпотентно. Меняет Email Account «PMK Park входящие (тест)»:
sync=ALL, From=аккаунт, append в «Отправленные», + IMAP Folder «Отправленные» (pull).

## Задача 2 — отправленные подтягиваются (главное)
- [ ] 1. Ответить/написать с ДРУГОГО устройства через веб-mail.ru или телефон
      (с pmkpark@mail.ru). Подождать ≤10 мин (или ручной синк).
      Ожидаем: письмо появилось в ERPNext, папка «Отправленные», sent_or_received=Sent.
- [ ] 2. Письмо, отправленное САМИМ ERPNext, НЕ задвоилось (дедуп по Message-ID).

## Отправка доходит / копия в Sent
- [ ] 3. Отправить из ERPNext на внешний ящик → дошло, From = pmkpark@mail.ru.
- [ ] 4. Веб-mail.ru → «Отправленные»: письмо из теста №3 там есть (имя папки верное).

## Приём всех входящих
- [ ] 5. Прислать на pmkpark@mail.ru, прочитать в веб-почте, подождать синк →
      письмо всё равно в ERPNext (режим ALL).

## Регрессия
- [ ] 6. Инбокс: колонки (имя/тема/почта раздельно), полки, папки, классификатор целы.

## Если что-то не так
- 550/ошибка auth при отправке → нужен пароль приложения mail.ru (создаёт Антон;
  в код/чат не писать).
- Дубли отправленных → проверить дедуп по Message-ID / отключить pull «Отправленные».
- Нет приёма из «Отправленные» → сверить имя папки (IMAP LIST: спец-флаг \Sent).
