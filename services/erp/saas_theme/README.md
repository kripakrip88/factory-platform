# saas_theme

Встроенная тема интерфейса ERPNext — форк [vineyrawat/saas_theme](https://github.com/vineyrawat/saas_theme) (version-16).

Подключается через `Dockerfile` как локальный Frappe-модуль.
Для изменения дизайна — редактировать файлы в `saas_theme/public/css/` и `saas_theme/public/js/`,
затем пересобрать Docker-образ.
