# ERPNext Service

ERPNext-based ERP core with custom `factory_core` app.

## Stack

- ERPNext (Frappe Framework, Python)
- MariaDB
- Redis

## Setup

> To be configured. ERPNext runs as a separate Docker container.
> See `infra/docker-compose.yml` for integration.

## Custom App

`factory_core` — custom Frappe app with:
- CRM customizations
- Quotation workflow
- Engineering module
- BOM/Production extensions
- AI integration hooks
