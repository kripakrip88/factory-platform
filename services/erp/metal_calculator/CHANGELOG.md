# Changelog — metal_calculator

## Раскрой металла (feature/metal-cutting)
- Модуль раскроя внутри metal_calculator (изолирован, не трогает калькулятор/справочники).
- DocTypes: Cutting Plan, Cutting Plan Item, Stock Length (не связаны с Item/Work Order/BOM ERP).
- Линейный раскрой (1D, First Fit Decreasing) с учётом kerf, группировка по сортаменту.
- Листовой гильотинный раскрой (2D, полочный shelf) с поворотом детали на 90°, SVG-карты.
- Кнопка «Добавить в раскрой» в калькуляторе веса → накопительный Cutting Plan.
- Размеры заготовки задаёт человек (без авто-дефолта); деловой остаток не выделяется.
- Юнит-тесты test_cutting_linear / test_cutting_sheet.

## Доборные элементы (feature/dobor-elements)
- Модуль доборных элементов внутри metal_calculator (изолирован от калькулятора/раскроя).
- DocTypes: Dobor Coating (справочник цветов, seed Цинк+RAL), Dobor Profile (библиотека
  шаблонов сечения), Dobor Order Item (позиция доборки в заказе со снимком профиля).
- Расчёт развёртки/веса (server-side calc): развёртка = полки + завальцовки, без поправки
  на гиб; вес через Metal Sheet Grade; полос из рулона. Юнит-тесты по эталонам прототипа.
- Конструктор профиля (Frappe Page dobor_builder): рисование мышкой, перетаскивание точки,
  правка размеров на чертеже, авто-вписывание, эскиз с загибами 180°/завальцовкой/замком,
  выбор цвета из справочника, библиотека шаблонов, накопление «Доборки в заказе».
- Раздел «Доборные элементы» воркспейса — рабочий (заглушка заменена на страницу).
