# metal_calculator — Калькулятор веса металлопроката

Изолированная frappe-аппа внутри ERPNext v16. Считает вес конструкционной стали
**строго по справочным таблицам ГОСТ** (никакой геометрии: вес = таблица × длина × количество).

**Статус:** итерация 1 — автономный калькулятор (считает и показывает вес).
Подстановка в Номенклатуру / BOM / КП — НЕ в этой итерации.

## Принципы

- **Только конструкционная сталь.** Плотность ~7850 кг/м³.
- **Марка стали на вес не влияет** — выбирается как атрибут, прокидывается в результат.
- **Вес строго из ГОСТ.** Если для типоразмера нет справочного значения — его в калькуляторе нет.
- **Полная изоляция.** Свои DocType, без Link на стандартные `Item`/`UOM`/`Item Group`.
  Удаление аппы не влияет на остальной ERPNext.

## Состав

| Компонент | Назначение |
|-----------|-----------|
| DocType `Metal Profile` | Линейный прокат (кг/м): арматура, двутавр, швеллер, уголок, круг, квадрат, шестигранник, трубы |
| DocType `Metal Sheet Grade` | Лист — масса 1 м² по толщине (ГОСТ 19903-2015) |
| DocType `Steel Grade` | Справочник марок стали (атрибут) |
| `api.calculate` | Whitelisted-расчёт, конвертация мм→м внутри |
| Page `metal_calculator` | UI калькулятора (рус.) |
| Page `module_in_progress` | Заглушка для будущих разделов |
| Workspace `Калькуляторы` | Воркспейс с 3 разделами (fixture) |

## Источник данных

Справочники — в [`metal_calculator/seed_data.py`](metal_calculator/seed_data.py).
Значения кросс-проверены по ≥2 источникам. Двутавр (серия Б) — по действующему
**ГОСТ Р 57837-2017** (контрольный якорь 20Б1 = 21.3 кг/м соответствует ему;
старый ГОСТ 26020-83 давал 22.4). Лист — масса 1 м² = толщина(мм) × 7.85.

Сид идемпотентный: `after_install` + патч `seed_gost_reference` (на `bench migrate`).

## Установка (на сервере)

Аппа вшивается в образ через `services/erp/Dockerfile`. После пересборки образа:

```bash
bash services/erp/scripts/install-metal-calculator.sh
```

## Тесты

```bash
bench --site erp.localhost run-tests --app metal_calculator
```

Эталоны: двутавр 20Б1 (L=6000, n=10) → 1278 кг; швеллер 16У (L=6000) → 85.2 кг;
лист 4 мм (1500×6000) → 282.6 кг; + контроль конвертации мм→м.
