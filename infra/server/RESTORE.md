# Восстановление всего из бакета Яндекса

Odoo (erppark.ru) и сайт (pmkpark.ru) поднимаются **только из бакета** `pmkpark-odoo-backup`
(Yandex Object Storage, облако cloud-ksu161ksu, каталог default). GitHub, Mac, Docker Hub, pypi и git.ruodoo.ru
не нужны. Время — 1–2 часа, потеря данных — не больше суток (бэкап каждую ночь в 04:20).

## Что лежит в бакете

| Папка | Что | Как часто |
|---|---|---|
| `kit/RESTORE.md`, `kit/restore-all.sh` | эта инструкция и скрипт | при изменении |
| `kit/code/factory-platform.bundle` | весь git: модули Odoo, скрипты сервера, сайта, nginx | при изменении |
| `kit/code/ruodoo.tar.zst` | локализация RuOdoo с нашей правкой (у RuOdoo нет истории версий) | при изменении |
| `kit/images/*.tar.zst` | образы Docker (Odoo, PostgreSQL, PHP сайта, MySQL, nginx, certbot) | при изменении |
| `kit/secrets.tar.zst.enc` | пароли баз, `odoo.conf` (ключ почты!), ключ бакета, ключ туннеля — **зашифровано** | при изменении |
| `odoo/db/` | дамп базы Odoo | каждую ночь, хранится 30 дней |
| `odoo/filestore/` | вложения Odoo по файлам | каждую ночь, только новые |
| `site/db/` | дамп базы сайта | каждую ночь, 30 дней |
| `site/www/` | файлы сайта | каждую ночь, только изменённые |
| `archive/` | дамп 22.10 со старого сервера | разово |

## Что нужно иметь

1. **Пароль комплекта** — в менеджере паролей Антона («PMK: пароль комплекта восстановления»).
   Без него не открыть `secrets.tar.zst.enc`. Остальное восстановится, но придётся заново вписать
   пароли почты (у шифрования почты свой ключ — он в секретах).
2. **Ключ к бакету.** Консоль Яндекса → Identity and Access Management → Сервисные аккаунты →
   `pmk-backup-writer` → «Создать новый ключ» → «Статический ключ доступа» (ID + секрет).
3. **Новый сервер** Ubuntu 24.04, от 4 ядер / 8 ГБ / 60 ГБ, доступ root. У любого хостинга.

## Порядок

1. Скачать `kit/restore-all.sh` из консоли Яндекса (Object Storage → бакет → kit → скачать) и положить на сервер.
2. На сервере от root:
   ```
   export YC_KEY_ID=<ID ключа> YC_SECRET=<секрет> YC_BUCKET=pmkpark-odoo-backup
   bash restore-all.sh
   ```
   Спросит пароль комплекта. Дальше сам: пакеты, код, секреты, образы, Odoo с базой и вложениями,
   сайт с базой и файлами, nginx, ночные бэкапы.
3. DNS (сейчас — панель Бегета): `erppark.ru`, `www.erppark.ru`, `pmkpark.ru`, `www.pmkpark.ru` → A новый IP.
4. После DNS — сертификаты (скрипт в конце печатает команды):
   `bash /opt/factory-platform/infra/edge/edge.sh cert erppark.ru www.erppark.ru` и то же для pmkpark.ru.
5. Проверить: https://erppark.ru/web/login (вход — прежние логины), https://pmkpark.ru/.

## Если чего-то не хватает

- Нет пароля комплекта: восстановить можно, но `.env` и `odoo.conf` придётся создать заново
  (`experiments/odoo/install.sh` их генерирует), и пароли почтовых ящиков вписать заново.
- Ассистент (pmk_ai) ходит к Anthropic через туннель на NL-сервер `31.77.141.89` — ключ туннеля в секретах;
  если NL-сервера нет — см. `infra/server/README.md`, раздел «Сеть».
- Подробно о сервере — `infra/server/README.md` в коде.
