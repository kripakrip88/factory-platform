деплой в develop = тег + запись здесь. Откат: `git checkout vX.Y.Z` → деплой.

## v1.2.1 — 2026-06-22
Фикс регистрации/смены пароля (страница /update-password) + брендинг (текст) + настройки входа:
- [fix] **корень бага**: фронт-nginx редиректил `/` на `/desk` для ВСЕХ методов
  (`location = / { return 302 /desk; }`), поэтому `POST /` (легаси `frappe.call` с `cmd`,
  который шлёт страница `/update-password` и др. web-формы) ловил 302 → форма не задавала
  пароль (молча перезагружалась). Починено в `services/erp/Dockerfile`: редирект `/`→`/desk`
  только для GET, остальное (POST) → backend (`@webserver`). Проверено: `POST / cmd=ping`=pong,
  `GET /`=302, форма задаёт пароль, вход 200, ключ очищается.
- [config] срок жизни ссылки сброса `reset_password_link_expiry_duration` 1200с(20мин)→604800с(7д);
  политика паролей `enable_password_policy` выкл (по согласованию — проще сотрудникам). prod+staging.
- [feat] `saas_theme.sales_manager_role.reset_link` — прямая ссылка задания пароля (sha256-хеш
  ключа как в ядре Frappe), отдать админу без зависимости от доставки почты.
- [feat] `saas_theme/branding.py` — брендинг «ПМК Парк» штатными Website/Navbar Settings (текст;
  лого позже). app_name на входе/вкладке. Применён текст на staging.
- Прецедент: было потрачено много времени на ложные версии (bk.ru/политика/срок) — реальная
  причина в nginx-редиректе на все методы.
