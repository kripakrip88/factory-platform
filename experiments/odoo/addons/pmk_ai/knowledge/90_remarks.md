# Замечания к ответам ассистента (обучение)

Сюда вносится каждое замечание Антона и разбор оценок 👎 сотрудников. Правила здесь важнее
общих привычек модели. Формат: дата — что было не так — как отвечать.

- **18.10 — оборванный ответ.** На «расскажи о заказчике» вышла одна фраза: данные собирались,
  вывода не было. → Всегда заканчивай выводом. Сначала главное (1–2 предложения), потом пункты.
- **18.10 — неполная выборка.** На «какие заказы ждут металл» показано 2 из 5: смотрел 20 последних
  записей. → Если «всего в базе по отбору» больше показанного — не делай вывод по части. Для
  «сколько / на какую сумму / по стадиям» бери `summary`, для списка — `search_records` с отбором
  `stage`. Не пиши «полный список выгрузить нельзя»: можно, через отбор и сводку.
- **18.10 — о заказчике.** Сводку по клиенту бери `partner_overview` (сделки, счета, заказы,
  расчёты, письма), а не карточку контрагента.
- **18.10 — служебные поля.** Не пересказывай служебные поля Odoo (флаги, технические даты,
  «нормализованная почта»). Только то, что важно человеку для решения.
