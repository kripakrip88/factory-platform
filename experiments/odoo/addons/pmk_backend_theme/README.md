# ПМК Парк — тема бэкенда Odoo (`pmk_backend_theme`)

Собственная тёмная тема, написанная с нуля под штатные классы веб-клиента
Odoo 19. Не зависит от `theme_liquid_glass` и не патчит её — те же классы
переопределены заново, без глассморфизма/блюра.

## Откуда цвета

Фирменные значения — из `design-system.css` на pmkpark.ru:

| Токен | Значение | Смысл |
|---|---|---|
| `$accent` | `#C8F000` | фирменный лайм — все primary-кнопки, активные вкладки, ссылки |
| `$accent-ink` | `#16191C` | текст НА лайме (лайм светлый, белый текст не читается) |
| `$danger` | `#E5564A` | = `--pmk-danger` компании |

Поверхности тёмной темы (`$bg-page`/`$bg-surface`/`$bg-surface-2`) выведены из
тёмного `ink` компании — не заимствованы у купленной темы.

## Что покрыто (одним архивом, per всем восьми SCSS-файлам)

Навбар, кнопки (primary/secondary/link/light/stat-button), форма (лист,
статус-бар, ячейка, вкладки notebook), списки, канбан, модалки. Все
селекторы сверены по реальному коду — либо уже встречены в `pmk_theme`, либо
взяты из архива `theme_liquid_glass-19.0.1.0.0.zip` (тот же DOM, Odoo 19
общий), а не угаданы.

## Что сознательно НЕ покрыто

- **Светлая тема.** У самой Odoo 19 / купленной темы её не было вообще —
  добавить нужно вторым набором значений токенов и `[data-theme="light"]`,
  это отдельный заход, не входит в эту версию.
- **Боковой ящик приложений** (`.o_apps_sidebar`, `navbar_sidebar.js` в
  купленной теме) — отдельный JS-компонент, не только CSS. Не переносился,
  потому что дублирует то, что уже даёт постоянно видимая горизонтальная
  навигация `pmk_theme` (модуль-бар + подменю). Без `pmk_theme` штатный
  переключатель приложений Odoo останется нестилизованным — не ломает
  интерфейс, просто не в цвет темы.
- **Почта** (`vendor/mail_client`, `pmk_mail_ui`) и **калькуляторы**
  (`pmk_calc`, SVG-холст доборки) — своя цветовая логика в других модулях,
  сюда не входит.

## ⚠️ Важно перед установкой рядом с `pmk_theme`

`pmk_theme/static/src/scss/forms.scss` уже переопределяет `.o_cell` и
`.o_form_statusbar` — те же селекторы трогает и этот модуль. Если оба
установлены одновременно, порядок в бандле `web.assets_backend` решает, чьё
правило победит (обычно — порядок зависимостей/установки, не алфавит папок).

Два безопасных варианта, а не устанавливать вслепую вместе:

1. Проверить на staging с выключенным `pmk_theme`, отдельно оценить визуально.
2. Или сразу отдать разработчику для слияния в `pmk_theme` (заменить его
   секции «Тёмная тема» / «Ячейки формы» в `forms.scss` содержимым отсюда).

## Установка

```bash
# скопировать папку pmk_backend_theme в addons-путь Odoo, затем
# Настройки → Технические → Обновить список приложений → установить
```

## Проверить на живом стенде (не сделано мной — я не подключён к серверу)

- Контраст текста на `$bg-field`/`$bg-surface-2` при реальном рендере шрифта.
- Конфликт с `pmk_theme` по `.o_cell`/`.o_form_statusbar` (см. выше).
- Кнопка `.btn-primary` на модулях, где `--acc-x` переопределён `pmk_theme`
  под цвет раздела — проверить, не перебивает ли она акцент обратно.
