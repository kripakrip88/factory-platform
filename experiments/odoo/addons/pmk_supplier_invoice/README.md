# pmk_supplier_invoice — счета поставщиков → цены

«Закупки → Счета поставщиков». Антон 25.10.2026: входящие счета на оплату от поставщиков —
для постоянного обновления цен. Проверяет и жмёт «Обновить цены» Голубенко (первые недели —
только по кнопке). Цена из счёта — обычная цена поставщика с датой счёта, как прайс.

## Как работает

1. **Отбор писем (бесплатно)** — «Входящие» ящика разбора почты (`pmk_ai_mail.account`,
   pmkpark@mail.ru) после `pmk_supplier_invoice.since`, с вложением, в теме «счёт»
   (`[сc]ч[её]т` — Металлсервис пишет «Cчет» с латинской C), не «Re:», не от нас.
   Вкл/выкл — `pmk_supplier_invoice.enabled`. Счёт можно загрузить и вручную («Новый» + файл).
2. **Распознавание** — фон ассистента (odoo-ai-worker, по одному счёту), вложения — как у
   разбора почты (`pmk_ai_mail.tools.parts`). Счёт Металлсервиса — PDF-картинка: ≈3–8 с,
   ≈1 ¢. Правила — `knowledge/invoice.md`. Лимит месяца — общий с ассистентом.
3. **Сопоставление** — тот же разборщик, что у прайсов (`pmk_bridge/tools/vendor/match.py`),
   по названию в словах справочника от ассистента; сторожа: вид из исходной строки, числа
   размера, масса метра счёта против справочника (±10 %). Выбор вручную запоминается для
   поставщика (`pmk.supplier.invoice.alias`).
4. **Цена** — с НДС, за единицу карточки (метр; лист — «Лист WxL»), масса — из счёта
   (тонны / погонные метры из «Прим.»), без неё — справочника.
5. **«Обновить цены»** — ряд цен поставщика (уровень 1), как загрузчик прайсов: новая цена
   с датой счёта закрывает прошлый период; счёт старше последней цены встаёт в свой период.
   Цена — в тот же ряд (вариант марки), где уже лежат цены этого поставщика.

## Поставщик

Карточка, на которой лежат его цены: выбор из прошлых счетов с этим ИНН (с записанными
ценами) → карточка с ИНН и ценами → поставщик с ценами, в названии слово из счёта →
карточка с ИНН. (Металлсервис: цены — у «АО «Металлсервис», филиал Хабаровск» без ИНН,
а «ООО «МЕТАЛЛСЕРВИС-ХАБАРОВСК»» с ИНН — из МойСклада, без цен.)
