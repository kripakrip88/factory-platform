## Как ставить (по правилу «сначала копия»)

1. Слить `feature/kolodec` в `feature/experiment-carbon` (или cherry-pick коммитов модуля).
2. `deploy.sh`: добавить `pmk_kolodec` в `OURS` (после `pmk_bolt`, с комментарием, как у болтов) — иначе
   модуль не разложится и не будет обновляться.
3. **Копия :8099**: первый раз `INSTALL="pmk_kolodec"`; бэкап — как обычно.
4. Тесты в Odoo: `--test-tags /pmk_kolodec` (на копии или в отдельной тест-базе).
5. Антон смотрит на копии → только по его фразе «выкладывай vX на боевой» → бэкап → боевой
   (`INSTALL="pmk_kolodec"`), тег + CHANGELOG по протоколу.

1. Калькуляторы → «Металлоизделия колодцев» → Создать → в таблице: `с1-04 10шт`, `с-5 901`,
   `стремянка нр 1800`, `мс-5 100шт`, `мн1`, `проставка ду300`, `зо`, `к1`, вставка столбика названий из
   счёта МС. Под записью — название по альбому, пометки жёлтым, «Прошлые продажи».
2. Состав: уголок 50×5 — цена по прайсу; **круг ⌀18 — «нет цены»** (так и должно быть: Антон «ничего не
   придумываем»); пластины МС, полосы ЗО, накладка/ручки К1 — по цене листа той же толщины.
3. Проставка — пометка «эскиз», покупные (шпильки, гайки, уплотнение) — «нет цены», вписать.
4. Справочник: 53 строки, «Детали / альбом, %», С1-13…18 серым «вне альбома».
5. «Поправка на гиб круга»: поменять ⌀18 на 1,5 → новая строка `мн1` → заготовка 742.
6. Вся форма документа и соседние калькуляторы (болты, опоры) — не съехали (правило Антона №10).
