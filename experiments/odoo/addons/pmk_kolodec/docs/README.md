# pmk_kolodec — металлоизделия колодцев

Калькулятор (Калькуляторы → «Металлоизделия колодцев») и справочник (Справочники →
«Справочник изделий колодцев») по типовым альбомам колодцев. Сделан по образцу опор
(`pmk_opora`) и болтов (`pmk_bolt`): строка — изделие, под ним состав деталей, ввод в таблице Бутика.

## Что считает

| Изделие | Альбом | Марки | Продажи (МС, 2022–2026) |
|---|---|---|---|
| Стремянка С1 | ТПР 902-09-22.84, ал. VII | С1-00…С1-12; С1-13…С1-18 — вне альбома | ≈1700 шт |
| Стремянка С | ТПР 901-09-11.84, ал. V | С-1…С-9 | ≈60 шт |
| Элемент соединительный МС | ТПР 901-09-11.84, ал. VI.88 и 902-09-22.84, ал. VIII.88 (одно изделие) | МС-1…МС-8 | ≈9000 шт |
| Скоба ходовая МН1 | ТПР 901-09-11.84, ал. V | МН1 | ≈260 шт |
| Проставка монтажная (эскиз) | ТПР 901-09-11.84, ал. II, черт. 1219.01.000 | Ду 100, 150, 300, 400, 500, 600 | не предлагали |
| Звено ограждения ЗО | ТПР 902-09-22.84, ал. VII | ЗО | — |
| Крышка металлическая К1 | ТПР 902-09-22.84, ал. VII | К1 | — |

Запись строкой: «с1-04 10шт», «с-5 901», «стремянка 1,8 м», «мс-5 100шт», «мн1», «проставка ду300»,
«зо», «к1»; понимает и названия из счетов МоегоСклада («Стремянка водопроводного колодца С-1-04
(длина лестницы 1,8 м) ТПР 902-09-22.84»). Стремянки НТС 62-91-111А и ЛС1–ЛС3 — другое изделие,
калькулятор их отклоняет.

## Решения (по образцу опор и болтов, 25.10.2026)

- Масса — **по фактическим деталям**, масса альбома — рядом («По альбому, кг»), в справочнике —
  процент «Детали / альбом». В альбомах есть ошибки — см. `TPR_*.md`.
- Себестоимость — только материалы. Прокат и лист — по прайсам (₽/т, `_pmk_find_seller`, Ст3 —
  самая дешёвая марка, 09Г2С — только своя). Нет позиции или цены — «нет цены», соседний размер
  и другой прокат не подставляем.
- **Полоса = лист** (Антон 25.10.2026: «полоса — это фактически лист, мы его режем на лазере»):
  пластины МС, полосы ЗО, накладка и ручки К1 — по цене листа той же толщины.
- **Гибы круга** (Антон 25.10.2026): каждый гиб убирает с развёртки 2 диаметра, как у фундаментных
  болтов; коэффициент на диаметр технолог правит в «Справочники → Поправка на гиб круга» (по
  умолчанию 2). МН1: 850 − 4·2·18 = 706 мм.
- Покупное (шпильки, гайки, уплотнение, болты К1) — цену вписывают, подсказка «было … ₽» — последняя
  вписанная цена той же строки.
- Наценка — «Ценовая политика», вид «Металлоизделия колодцев» (стартовая 45 %, как у болтов и опор).

## Открыто и решения по ценам

- **Круг ⌀18 (ступени, МН1) — в прайсах цены нет.** Решение Антона 25.10.2026: «ничего не придумываем,
  оставляем нет цены» — арматуру и другие позиции не подставлять, цену вписывают в строке.
- Труба 108×5,5 (проставка Ду 100) — в справочнике нет, «нет цены».
- Проставки — эскиз: состав собран по ГОСТ 12815-80 (Ру 1,0), проверить Игорю; фланцы 20–31 мм лазер режет (Антон 25.10).
- К1 (ручки, накладка) и проставки — задачи на проверку Игорю Бутову.

## Как устроено

| Файл | Что |
|------|-----|
| `tools/alb902_7.py` | ТПР 902-09-22.84 ал. VII: стремянки С1, ЗО, К1 |
| `tools/alb901_5.py` | ТПР 901-09-11.84 ал. V: стремянки С-1…С-9, МН1 |
| `tools/alb901_6.py` | МС-1…МС-8: ТПР 901-09-11.84 ал. VI.88 (вид ms) и 902-09-22.84 ал. VIII.88 (ms902) |
| `tools/alb901_2.py` | ТПР 901-09-11.84 ал. II: проставки монтажные (эскиз) |
| `tools/common.py` | массы проката, материалы состава |
| `models/bend.py` | «Поправка на гиб круга» — вычет на гиб по диаметру (технолог) |
| `tools/catalog.py` | диспетчер: модели зовут только его |
| `tools/parse.py` | запись строкой и названия из счетов МС |
| `models/kolodec.py`, `part.py`, `grid.py` | документ расчёта, строки, состав, таблица |
| `models/ref.py` | справочник — собирается из файлов альбомов при установке/обновлении |

**Править справочник** — править файл своего альбома и его `docs/TPR_*.md`, затем обновить модуль
(`-u pmk_kolodec`): справочник пересоберётся сам.

## Выкладка

Пошагово, что проверить и что не запускалось — **`docs/HANDOFF.md`**.

Модуль ставит в систему **соседний чат** после тестов (Антон 25.10.2026). Первый раз —
`INSTALL="pmk_kolodec"`, зависит от `pmk_bolt` (ценовая политика), `pmk_butik` (таблица),
`pmk_bridge` (прайсы), `pmk_calc` (меню). Тесты: `tests/test_kolodec.py` — классы TestAlbums и
TestParse проверены вне Odoo, TestCalc (документ, таблица, справочник) — только в Odoo.
