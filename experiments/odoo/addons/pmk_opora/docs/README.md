# pmk_opora — опоры трубопроводов

Калькулятор (Калькуляторы → «Опоры трубопроводов») и справочник (Справочники → «Справочник опор»)
опор трубопроводов по отраслевым стандартам. Сделан по образцу фундаментных болтов (`pmk_bolt`):
строка — опора, под ней состав деталей, ввод в таблице Бутика.

## Решения Антона (25.10.2026)

- Масса — **по фактическим деталям**, масса ОСТ («не более») — рядом, для сверки
  (в справочниках ОСТ есть ошибки — Игорь находил при подготовке чертежей).
- Подвижная и неподвижная — **разные категории изделия**, не галочка.
- Корпус по умолчанию **гнутый**, «С» в исполнении — сварной.
- У рёбер в гнутом корпусе — **фаски нижних углов под радиус гиба** (r + 2 мм).
- Себестоимость — только материалы: лист по прайсам (марка стали опоры), болты и гайки —
  покупные, цену вписывают. **Наценку ставит менеджер** (в строке или в «Ценовой политике», вид
  «Опоры трубопроводов»); модуль готовой наценки не заводит — без неё цены нет («45 % — очень мало»).
- Встройку в «Расчёт» и счёт, тесты и проверки перед выкладкой делает **отдельный чат**.
- Каждый справочник правится **отдельно**.

## Как устроено

| Файл | Что |
|------|-----|
| `tools/ost36_146.py` | ОСТ 36-146-88: КП, КХ — таблицы, состав, проверки, название |
| `tools/ost36_94.py`, `tools/ost36_94_mass.py` | ОСТ 36-94-83: ОПП1 с составом; масса всех 289 марок по приложению |
| `tools/catalog.py` | диспетчер: модели зовут только его, он отдаёт вызов файлу стандарта |
| `tools/parse.py` | запись строкой: «кх а12 219 09г2с 20шт», «опп1-100.18», названия из счетов МС |
| `models/opora.py`, `part.py`, `grid.py` | документ расчёта, строки, состав, таблица |
| `models/ref.py` | справочник: собирается из файлов стандартов при установке/обновлении модуля |
| `docs/OST_*.md` | по стандарту: источник, что собрано, допущения, открытые вопросы |

**Править справочник** — править файл своего стандарта (`tools/ost36_146.py` или `tools/ost36_94.py`)
и его `docs/OST_*.md`, затем обновить модуль (`-u pmk_opora`): справочник пересоберётся сам,
другие стандарты не затрагиваются.

**Добавить стандарт:** файл `tools/<стандарт>.py` с тем же набором функций (см. шапку
`tools/catalog.py`), строка в `catalog.STANDARDS`, `docs/<стандарт>.md`, тесты.

## Чертежи

Генераторы PDF (А3 по ГОСТ) и DXF под лазер (слои CUT/BEND) — вне репозитория, как у закладных МН:

- `~/Projects/opory_ost36-146/drawings/kx_a12.py <Дн> [сталь]` — КХ А12;
- `~/Projects/opory_ost36-94/drawings/opp1.py <Дн> [100|70] [сталь]` — ОПП1.

Общая библиотека рамки и штампа — `~/Projects/mn_zakladnye/drawings/gost_draw.py`.

## Выкладка

Модуль ставит в систему **отдельный чат** (Антон 25.10.2026). Первый раз — `INSTALL="pmk_opora"`,
зависит от `pmk_bolt` (ценовая политика), `pmk_butik` (таблица), `pmk_bridge` (прайсы).
