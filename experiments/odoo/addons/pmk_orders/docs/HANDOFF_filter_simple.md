# Окно фильтра проще — передача на выкладку

Ветка `feature/filter-simple` (от `feature/experiment-carbon` @ 57a2e81). Сделано в отдельном
чате 25.10.2026; **на сервер и копию :8099 не ставилось** — выкладку ведёт соседний чат.

## Что решил Антон

«Окно фильтров перегружено, можно упростить и сделать удобнее» → разбор и прототип в чате →
«делай везде, без выкладки». Везде = все четыре списка с окном фильтра: Счета покупателям,
Расчёты, Сделки, Заказы в работе.

## Что изменено (только pmk_orders 19.0.1.6.0, база не трогается)

| Файл | Что |
|---|---|
| `static/src/js/filter_panel.js` | ряды по виду полей; новый вид поля `mine` («Мои счета / расчёты / сделки / заказы»); `tri` и `flag` — чипами «Показать только»; статусы МС группами «оплата · цех · прочее» (ключи как в МС, подписи короче); «Свой…» в периоде; свёрнутое штатное меню (запоминается в браузере); Enter в поле — «Показать» |
| `static/src/xml/filter_panel.xml` | новый шаблон окна: период чипами → поля в ряд → варианты → «Показать только» → «Ещё фильтры, группировка и избранное» + «Показать N» |
| `static/src/scss/filter_panel.scss` | ширина 780 px; штатные колонки скрыты, пока не раскрыты; выбранный чип — бледный лайм (тёмная — лайм словаря) вместо синего |
| `tests/test_filter_panel.py` | поля «Мои …» есть у моделей, ключи статусов МС, штатное меню свёрнуто, кнопка «Показать N» |

Запомненные условия в браузерах (localStorage `pmk_filter:*`) совместимы: ключи полей прежние,
`quick: "all"` старых записей читается как «Всё время».

## Порядок выкладки

1. Копия :8099: `-u pmk_orders` (уже в `OURS`), очистить `/web/assets`, сверить хеш бандла,
   консоль без ошибок (JS-модуль; перед rsync — `node --check` на копии .mjs).
2. Тесты: `--test-tags /pmk_orders:TestFilterPanel`.
3. Антон смотрит на копии → его фраза «выкладывай vX на боевой» → бэкап → боевой.
   Предлагаемая версия: **v1.119.0** (или вместе с шапкой v1.118.0).

## Что проверено до передачи

- логика условий в node на заглушках: домен и подпись плашки для периода, статусов, «Мои»
  (many2one `=` uid, many2many `in [uid]`), пар «да/нет», признаков; группы статусов; «Свой…» /
  «Всё время» для старых и новых запомненных значений;
- `node --check` (копия .mjs), разбор XML, сборка SCSS libsass;
- вид: статичная разметка по новому шаблону + новый CSS во вкладке боевого Chrome (только браузер):
  окно ~360 px вместо ~700, штатные колонки скрыты; строка статусов переносится на 2 строки.

## Что посмотреть глазами на копии (не проверено — нужен живой Owl)

- все четыре списка: Счета, Расчёты, Сделки, Заказы в работе (у Заказов — только окно
  планировщика, у доски «Доработка системы» фильтра нет);
- «Ещё фильтры, группировка и избранное» раскрывает штатные колонки, «Мои счета / Необходимо
  выставить / В допродажу», группировка и избранное работают как раньше;
- «Свой…» показывает даты, ввод даты → «Показать N» пересчитывается;
- «Показать N» применяет плашку «Фильтр: …», крестик на плашке забывает условия;
- выбор контрагента/организации (MultiRecordSelector) не закрывает окно;
- тёмная тема: чипы и плашка.

## Нагрузка

Без изменений: «N» — один `search_count` через 0,3 с после последнего щелчка, как и было;
список перезагружается только по кнопке.
