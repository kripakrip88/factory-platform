# pmk_bank — поступления из банка в Телеграм

**Статус:** 14.10.2026 — Модульбанк (ИП Чулков, р/с …8163). Точка — следующим шагом.

## Что делает
Раз в 5 минут забирает поступления на выбранные счета и присылает в группу
«ПМК ПАРК Офис» (тема для вида `money` — `/connect@Dv_laba_bot деньги` в ней):

```
💰 +11 500 ₽ — ООО «ЦК Дальний Восток»
🧾 Счёт 01183 от 08.10.2026 на 11 500 ₽ → оплачен полностью
ОПЛАТА ПО СЧЕТУ 01183 ОТ 09.10.2026 ЗА СНЕГОЗАДЕРЖАТЕЛЬ…
13.10.2026 · ИНН 2502075437 · ИП Чулков · р/с …8163
[🧾 Открыть счёт]
```

* Переводы между своими счетами (ИНН плательщика = ИНН организации) — не шлются.
* Счёт покупателю: номер из назначения + ИНН + сумма (номера повторяются по годам).
* Первый опрос счёта только запоминает, что было («было до подключения»):
  Модульбанк отдаёт дату операции без времени, правило «после момента
  подключения» потеряло бы платежи этого дня.
* Сам ничего не отмечает оплаченным — только показывает.

## Безопасность
* Токен Модульбанка: account-info + operation-history + web-notifications,
  **без operation-upload** (платёжки). Методов платежей в коде нет.
* Токен — системный параметр `pmk_bank.modulbank.token`, не в репозитории.
* Сертификат банка — УЦ Минцифры; проверяем по `data/russian_trusted_ca.pem`
  (официальный, gu-st.ru, SHA-256 D2:6D:2D:…:CF:31, до 2032), проверку не отключаем.

## Подключение (на боевой — только с одобрения Антона)
```python
env["ir.config_parameter"].set_param("pmk_bank.modulbank.token", "<токен>")
env["pmk.bank.account"].create({"org_id": <ИП Чулков>, "bank": "modulbank",
                                "number": "40802810470010208163"})
```
Первый опрос (cron или «Забрать сейчас») — без сообщений.

## Не умеет (пока)
* Вебхуки банка — только опрос раз в 5 минут.
* Точка (ИП Бутов, ИП Астахов) — ждёт ключа.
* Отметку оплаты в сделке/счёте — показывает, не ставит.
