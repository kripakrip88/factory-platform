## Порядок выкладки

1. Копия :8099: `-u pmk_theme,pmk_ai` (оба уже в `OURS` deploy.sh), очистить `/web/assets`,
   сверить смену хеша бандла.
2. Тесты на одноразовой базе: `--test-tags /pmk_theme:TestStep75NavbarTabs` + прежние
   тесты темы (test_step30/40/47/29 — читают navbar_nexus.scss).
3. Антон смотрит на копии → его фраза «выкладывай vX на боевой» → бэкап → боевой.
   Предлагаемая версия: **v1.118.0** (новый вид шапки).

## Что проверено до передачи

Собранный libsass CSS раздела вставлялся во вкладку боевого Chrome только на стороне
браузера (сервер не менялся), ширина 1463 px:
- Продажи / Производство / Настройки / форма сделки — вкладка с ножками ложится на
  карточку без стыка, черта карточки под вкладкой закрыта, разделители у соседей
  открытой прячутся;
- трей (✦, чат, часы, аватар) и переключатель темы — по центру вкладок; аватар 26 px;
- тёмная тема (класс `o_nexus_dark` на body только во вкладке): шапка = цвет панели
  под ней, карточка и вкладка на ступень светлее, плашка пункта — тон раздела.

- ширина 768–1100 px: строки модулей нет, карточка второй строки должна стоять под
  штатной кнопкой приложений (окно Chrome не уменьшилось — не снято);

  из низа `.o_navbar` скриптом — шапка стала на ~6 px выше);
- переключатель темы в тёмной теме (дорожка — старые правила, шагом 75 не трогалась);
- выпадающие меню трея и «Ещё» (если вернётся) открываются на месте.
