# pmk_telegram — бот в Телеграме

**Статус:** 07.10.2026, первая версия: только «Создать сделку».

## Зачем

Запрос прилетает в мессенджер или звонком, пока владелец не у компьютера.
Бот нужен, чтобы **не забыть** обращение, а не чтобы его обработать: этап,
текст или скриншот переписки — и сделка уже в воронке. Клиента, расчёт и всё
остальное заполняют потом с компьютера.

## Как выглядит

```
[ ➕ Создать сделку ]           ← постоянная кнопка внизу чата
Бот: Этап сделки?  [Заявка] [Расчёт] [Техэтап] [КП отправлено] [Выиграно]
Бот: Что нужно? Напишите текстом или пришлите скриншот переписки.
Вы:  текст и/или скриншоты (можно альбомом)
Бот: ✅ СД-00012 создана, этап «Заявка».  [Готово] [Открыть в Odoo]
```

Что попадает в сделку:

| Поле | Откуда |
|---|---|
| Название | первая строка текста (до 60 знаков); только картинка — «Запрос из Телеграма 07.10 14:32» |
| Описание | весь текст |
| Лента | запись «Из Телеграма» с текстом и скриншотами-вложениями |
| Этап | выбранный кнопкой |
| Ответственный | пользователь Odoo, к которому привязан Телеграм |
| Откуда пришёл | «Телеграм» (новый пункт к спискам `pmk_deal`) |
| Клиент | пусто — заполняется с компьютера |

Всё, что пришло после создания, дописывается в ту же сделку, пока не нажата
«Готово», не начата новая сделка или не прошло 30 минут тишины.

## Устройство

* `controllers/webhook.py` — адрес `https://erppark.ru/pmk_telegram/webhook`,
  на него Телеграм шлёт сообщения. Чужие запросы отсекаются секретом в заголовке.
* `models/bot.py` — весь диалог. Меню — список `MENU`: новая функция (заявка на
  снабжение и т.п.) = строка в нём + метод.
* `models/session.py` — где человек сейчас в диалоге (строка на чат).
* `models/telegram_api.py` — тонкий клиент Bot API без ORM.
* Вебхук с `max_connections=1`: сообщения идут по одному, альбом из трёх
  скриншотов не становится тремя сделками.

## Подключение (один раз)

Токен и секрет — в системных параметрах, **не в репозитории**:

```python
# odoo shell -d odoo
env["ir.config_parameter"].set_param("pmk_telegram.token", "<токен от @BotFather>")
env["pmk.telegram.bot"].pmk_setup_webhook()     # создаёт секрет и включает вебхук
env["res.users"].browse(2).pmk_telegram_id = "<ID>"
env.cr.commit()
```

Бот: @Dv_laba_bot. Антон — пользователь 2.

## Подключить ещё человека

1. Человек пишет боту `/start` — бот отвечает «Нет доступа. Ваш Telegram ID: …».
2. Настройки → Пользователи → нужный пользователь → «Предпочтения» →
   поле «Telegram ID» → вписать.

## Выключить

`setWebhook` с пустым url (или удалить параметр `pmk_telegram.token`) — бот
перестанет принимать сообщения; созданные сделки остаются.
