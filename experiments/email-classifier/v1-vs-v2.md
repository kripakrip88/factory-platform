# Замер v1 vs v2 на оценённых письмах (honest-сравнение)

Цель — доказать «v2 лучше v1» на ТЕХ ЖЕ письмах, где есть эталон (оценка
менеджера). v2 прогнан в отдельное поле `Классификация v2`, ответы v1 не
перезаписаны.

## Важно: очистка данных
До появления поля «Правильная полка» менеджер в 3 письмах правил поле
«Классификация Claude» руками → там лежала правка, а не оригинал Claude. Это
искажало замер (раздувало v1). Настоящий ответ v1 восстановлен из истории
изменений (Version), сравнение пересчитано на очищенных данных.

## Результат (42 письма с эталоном из 43 оценённых)

| Промпт | Угадал | Точность |
|--------|--------|----------|
| v1 (настоящий) | 35/42 | **83%** |
| **v2** | 36/42 | **86%** |

**Гейт ТЗ пройден: точность v2 (86%) ≥ v1 (83%).** Можно строить трубу на v2.

## Где v2 изменил решение (обезличенно: только полки)

**v2 ПОЧИНИЛ 5 ошибок v1:**
| v1 сказал | v2 сказал | эталон |
|-----------|-----------|--------|
| Вопрос по заказу | Поставщик | Поставщик |
| Вопрос по заказу | Поставщик | Поставщик |
| Поставщик | Спам | Спам |
| Поставщик | Спам | Спам |
| Прочее | Спам | Спам |

Все правила v2 про поставщиков сработали (роль отправителя; поставщик с заявками
≠ вопрос по заказу; только профильный поставщик = Поставщик).

**v2 СЛОМАЛ 4 ранее верных:**
| v1 сказал | v2 сказал | эталон |
|-----------|-----------|--------|
| Вопрос по заказу | Прочее | Вопрос по заказу |
| Вопрос по заказу | Прочее | Вопрос по заказу |
| Новая заявка | Прочее | Новая заявка |
| Поставщик | Спам | Поставщик |

**Оба мимо: 2** (в т.ч. 1 письмо без заполненной «правильной полки» — исключено
из базы 42).

## Вывод
- Чистый эффект: **+5 / −4 = +1** → v2 (36) > v1 (35).
- Правила про поставщиков — рабочие, в боевой промпт берём.
- Остаточный минус v2: перебарщивает с «Прочее» — иногда сваливает туда
  клиентские письма (Новая заявка / Вопрос по заказу). Это материал для v3
  (после недели наблюдения за трубой).
- Для первого боевого запуска (смотровой режим, без создания лидов) v2 годится:
  он точнее v1 и его ошибки — в сторону недоклассификации (Прочее), а не ложных
  заявок.

## Урок процесса
Поле «Классификация Claude» руками НЕ править — только Верно/Неверно + Правильная
полка. Иначе теряется оригинал модели и не с чем сравнивать.
