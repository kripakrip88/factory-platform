# Инбокс ERPNext — как работать (памятка)

**Открыть входящие:** в ERPNext перейти по адресу
`/app/communication/view/inbox` (или меню → поиск «Communication» → вид
«Inbox»). Слева вверху выбрать ящик **«PMK Park входящие (тест)»** — пойдёт
список входящих писем.

**Открыть письмо:** кликнуть по строке — откроется текст письма. Вложения
показаны в самом письме (в боковой панели «Attachments» / прямо в теле) —
кликом скачиваются/открываются (PDF, фото, Excel и т.д.).

**Привязать письмо к лиду:** в открытом письме поле **«Reference Document Type»**
= `Lead` и **«Reference Name»** = нужный лид (или создать новый лид и указать
его). После сохранения письмо появится в **таймлайне карточки лида вместе с
вложениями** — это и есть «единое окно».

**Создать лид из письма руками:** автосоздание лидов выключено намеренно
(спам-фильтра пока нет). Лид заводишь сам: New → Lead, заполняешь по письму,
затем привязываешь письмо к нему (см. выше).

**Важно:** новые письма подтягиваются автоматически (приём включён). Исходящая
почта НЕ настроена — отвечать из ERPNext пока нельзя, только читать и
разбирать входящие.
