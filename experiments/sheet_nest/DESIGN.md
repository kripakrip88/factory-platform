# sheet_nest — раскрой листового металла → программа CypCut (.lxds)

Статус: шаг 1 (12.10.2026, одобрено Антоном «поехали»). Отдельный модуль (принцип изоляции CLAUDE.md):
своя папка `experiments/sheet_nest/`, ветка `feature/sheet-nest`; в ERP — после проверки на станке.

Зачем: CypCut даёт раскладку не больше 20 листов; заказы больше — раскладывает наш инструмент. Образец —
решётки 1,5 цинк 12.10 (`~/Downloads/vent_nesting/reshetki/`, разовые скрипты): 77 листов (доказанный минимум),
холостой ход 506 м против 2241 м у порядка из блоков инженера.

## Поток

    вход (DXF из КОМПАСа/AutoCAD | программа CypCut с листами или без) → детали (Part)
    → раскрой (портфель: прямоугольный упаковщик pack_rect | растровый v1 пакета) → листы (Sheet)
    → порядок резки (route: змейка по рядам | оптимизатор) → .lxds (write_lxds, эталонный сборщик пакета)
    → проверки (verify) + картинка (render) + JSON

Общий код берётся из пакета раскроя зонтов `experiments/odoo/addons/pmk_vent_nest/lib/vent_nesting`
(cypcut/spec_rebuild — сборщик .lxds байт в байт с заводскими; lxds_reader — расшифровщик; nest.py — растровый v1)
через `sheet_nest/libpath.py`. Пакет НЕ меняется из этого модуля (кроме отдельных веток пакета по договорённости).
Только стандартная библиотека + numpy + Pillow (как в контейнере Odoo; scipy/ezdxf нет).

## Модель (общая для всех модулей)

Фигура (shape) — словарь как в `spec_rebuild` (тот же формат пишет сборщик):

    общее:  handle=None, kind, layer (1 — рез, 2 — гравировка), layer_name="0", coedge=0, flag64=0, outer=0|1, lead=None
    Line:        p1=(x, y), p2=(x, y)
    Circle:      c=(x, y), r, a0 (угол точки врезки, рад; по умолчанию π/4)
    LwPolyline:  verts=[(x, y, bulge), …], flag (бит 1 — замкнута), sp=0.0
                 bulge = tan(угол дуги/4), + — дуга против часовой (как DXF LWPOLYLINE)

Деталь (Part) — словарь:

    name: str            имя детали (в программе CypCut; без &<>"')
    qty: int             количество
    shapes: [shape]      в координатах детали; ВНЕШНИЙ КОНТУР ПОСЛЕДНИМ: LwPolyline замкнута, layer 1, outer=1
                         (окружность-деталь — Circle с outer=1); внутри: отверстия (замкнутые, слой 1),
                         открытые резы (слой 1, незамкнутые — прорези), гравировка (слой 2, любые)
    src: str             откуда (файл)
    warnings: [str]      что пропущено/приближено при чтении (текст, размеры, сплайн → дуги и т.п.)

Лист (результат раскроя): `{"W": 1250.0, "L": 2500.0, "amount": n, "placed": [{"part": i, "rot": 0|90|180|270,
"dx": .., "dy": ..}]}` — поворот против часовой вокруг начала координат детали, затем сдвиг (как
`spec_rebuild.transform_shape(s, rot, (dx, dy))`). Лист в координатах CypCut: X 0…W, Y 0…L.

### read_dxf.py — договорённость о гравировке
`parts_from_dxf(data: bytes, filename: str, qty=None, engrave_layers=None) -> [Part]`, ошибка — `DxfError` (по-русски).
- Слой гравировки — по имени слоя (код 8), без учёта регистра: «ГРАВИРОВКА», «Гравировка», «GRAV», «ENGRAVE»,
  «MARK», «МАРКИРОВКА», а также имя, содержащее «грав»/«engrav». Остальные слои — рез. Список переопределяется.
- Сущности: LINE, ARC, CIRCLE, LWPOLYLINE (bulge), POLYLINE+VERTEX (R12, bulge), SPLINE (приближение дугами/
  отрезками, отклонение ≤ 0,01 мм; предупреждение), ELLIPSE (так же), INSERT (блоки с масштабом/поворотом/сдвигом,
  вложенные), POINT — пропуск. TEXT/MTEXT/DIMENSION/HATCH/LEADER — не режутся: пропуск с предупреждением.
- Кодировка: AC1018 и старше — $DWGCODEPAGE (ANSI_1251 → cp1251), AC1021+ — UTF-8; escape \U+XXXX в строках.
- Единицы: $INSUNITS 4 (мм) / 0 (нет — считать мм, предупреждение) / 1 (дюйм ×25,4) / 5 (см ×10) / 6 (м ×1000).
- Сцепка рёбер в контуры с допуском 0,01 мм (как contours._node_ids пакета); замкнутая цепочка → LwPolyline flag=1;
  незамкнутая → LwPolyline flag=0 (на слое реза — открытый рез, на слое гравировки — гравировка).
- Несколько деталей в одном файле: внешний контур = замкнутый контур слоя реза, не лежащий внутри другого; всё,
  что внутри него, — его. Фигуры вне всех внешних — ошибка. Разрыв внешнего контура (не замкнулся) — ошибка
  с координатами разрыва.
- Внешний контур — против часовой, отверстия — по часовой (нормализовать направление).
- Количество: аргумент qty; иначе из имени файла (`…_12шт.dxf`, `… x12.dxf`, `…(12).dxf`); иначе 1 + предупреждение.

### pack_rect.py — прямоугольный раскрой
`pack_rect(items, W, L, gap, edge, rotations=(0, 90), node_limit=…) -> dict`
- items: `[{"id", "w", "h", "qty"}]` — габарит детали при повороте 0 (w — вдоль X листа, h — вдоль Y).
- Результат: `{"sheets": [[{"id", "rot", "x", "y", "w", "h"}]], "lower_bound": int, "optimal": bool, "method": str}`;
  x, y — левый нижний угол повёрнутого габарита; всё в [edge, W−edge]×[edge, L−edge]; между габаритами ≥ gap.
- Двухэтапный гильотинный: полосы вдоль Y (ширина полосы — по X), в полосе детали вдоль Y; полосы — рядом по X.
  И обратная ориентация (полосы вдоль X); лучшее.
- Точный случай: если в лист влезает только одна полоса (любые две детали поперёк не встают) — задача = 1D-упаковка
  вдоль Y; решать ТОЧНО (bin completion / ветви и границы с нижней границей L2 Мартелло–Тота, предел узлов) —
  решётки обязаны дать 77 листов при W=1250, L=2500, gap=edge=2.
- Нижняя граница: max(по площади габаритов с зазором, L2 для 1D-случая).

### Порядок резки (route.py)
- Внутри детали: элементы (отверстия, открытые резы, гравировка) путём от головки к точке врезки внешнего контура;
  внешний — последним. Открытые элементы можно развернуть.
- Ряды параллельных открытых резов (жалюзи) — змейка по рядам с рисками у концов (как у решёток); иначе —
  оптимизатор (ближайший сосед + 2-opt/перенос с разворотом). Берётся короче из вариантов БЕЗ переходов над
  вырезанным (язычок открытого реза, отверстие).
- Точка врезки внешнего контура: выпуклая вершина между прямыми участками, свободно ≥ 10 мм по наружной нормали
  к первому участку (край листа, соседи). Динамика по деталям листа.

### write_lxds.py
- Сборка через `spec_rebuild.compile_lxds` + `fresh_identity`; детали — блоки деталей как есть; раскладки — вставки
  с фигурами в порядке резки. Признак общего реза (coedge) — ТОЛЬКО у настоящих цепочек общего реза (шаг 2);
  открытые прорези — coedge=0 (так у CypCut инженера; правило пакета «открытая полилиния слоя 1 = общий рез» неверно).
- Технология (Technical/content.xml) — из входной программы CypCut, иначе шаблон пакета.
- Время сохранения — заводское UTC+10 (как в пакете).
- Один файл на материал на нужное число листов (CypCut читает файлы любой длины; ограничение 20 листов — только
  на его собственный раскрой).
