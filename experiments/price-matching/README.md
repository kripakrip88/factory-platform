# Разбор прайсов поставщиков

Прототип. В основной стек не подключён, из модулей Odoo не вызывается —
по принципу изоляции из `CLAUDE.md`.

## Задача

Одну и ту же позицию поставщики называют по-разному:

```
Труба профильная 40х20х1,5 ГОСТ 13663-86
Профтруба 40*20*1.5
Труба проф. 40 х 20 х 1.5 ст3сп
```

Всё это — наша позиция «Труба профильная прямоугольная 40x20x1.5».

## Главная мысль

**Это не задача для искусственного интеллекта.** Номенклатура металлопроката
структурирована: вид проката + размеры + марка стали. После нормализации
написания размеры совпадают ТОЧНО, и сопоставление становится обычным поиском
по ключу — предсказуемым, мгновенным и бесплатным.

ИИ нужен только на остатке: строки, которые не разобрались правилами.
Их будет меньшинство, и каждая разбирается один раз — подтверждённое
соответствие запоминается за поставщиком.

## Как устроено

| Шаг | Что делает |
|---|---|
| 1. Нормализация | разделители (`×`, `х`, `x`, `*`) к одному виду, запятая в дробях к точке, сокращения разворачиваются (`проф.`, `уг.`, `шв.`, `б/ш`, `г/к`), ГОСТ и марка стали вынимаются отдельно |
| 2. Вид проката | по ключевым словам, 12 наших видов. Порядок правил важен: узкие раньше общих, иначе «профильная труба» съест «труба» |
| 3. Размеры | связка чисел через разделитель либо одиночное число. Приставки (`d`, `ф`, `Ду`, `S`, `№`) снимаются ДО поиска |
| 4. Сопоставление | точное совпадение по ключу «вид + числа» |
| 5. Остаток | всё, что не разобралось — сюда и зовём ИИ |

## Что оказалось неочевидным

**Квадратная или прямоугольная профильная труба решается числами, а не
словом.** `40x40x2` квадратная, `40x20x2` прямоугольная — поставщики обе
называют «профтруба».

**Швеллер и двутавр — не размер в миллиметрах, а обозначение по ГОСТ**:
`10П`, `20Б1`, `15К2`. Номер бывает дробным (`6,5У`), буква двойной (`16аУ`).
Цифру в серии нельзя считать числом размера, иначе `20Б1` превращается
в (20, 1) и ключ разъезжается.

**Бесшовная и электросварная круглые трубы** лежат у нас отдельными позициями,
отличие зашито прямо в размер (`108x4 бесш`). Слово из прайса и решает, какую
из двух брать. Без этого одна строка прайса даёт два кандидата.

**Приставка к размеру ломает границу слова.** В `ду25x3.2` между «у» и «2»
нет границы слова, и связка размеров не находится вовсе. Приставки надо
снимать до поиска чисел — на этом спотыкалась вся ВГП.

## Проверка

Две проверки, и вторая важнее.

**На себе** (`selftest.py`): каждая позиция справочника прогоняется в пяти
стилях написания и должна вернуться сама. 665 из 665, 100%. Это нижняя планка:
разборщик узнаёт свою же номенклатуру.

**На живых данных** (`realtest.py`, `real-names.json`): 437 настоящих строк,
снятых с сайтов Град Стали, МеталлСити, ДМК, Феррума, СПК, А ГРУПП и
СтальГрада — включая настоящий PDF-прайс склада.

| | строк | доля |
|---|---|---|
| сопоставлено | 311 | 71,2% |
| нет в нашем справочнике | 61 | 14,0% |
| нужен выбор человека (швеллер без серии) | 29 | 6,6% |
| заголовки разделов без размера | 18 | 4,1% |
| вида нет в справочнике (полоса, катанка) | 13 | 3,0% |
| лист: толщина | 7 | 1,6% |
| **промахи разборщика** | **2** | **0,5%** |

Обе оставшиеся строки — фитинги («Переход 89х3,5-76х3,5», «Отвод короткий»),
их разборщик обязан отбрасывать. То есть настоящих промахов ноль.

Первый прогон по живым данным дал 58%. Дальше каждая правка была подсказана
самими данными, а не догадкой:

- «Угол» вместо «Уголок» — так пишет весь каталог Феррума: +26 строк;
- «Трубы профильные» во множественном числе — название раздела каталога: +6;
- круглая труба с ТРЕМЯ размерами — это профильная, поставщик просто не
  написал слово: +21;
- «Квадрат 10х10» — это наш «10», сторона названа дважды: +8;
- «Уголок равнополочный 20 х 4» — два числа вместо трёх, полка названа один
  раз, достраиваем до 20x20x4: +25.

## Главная польза, которой не ждали

**14% живых позиций отсутствуют в нашем справочнике.** Разборщик находит их
сам: профильная труба 10x10x1.5, 20x10x1.5, 20x20x3, 60x30x1.5, круглая
Ø219x5, два десятка уголков, восемь квадратов. Плюс три вида, которых нет
вовсе: полоса, катанка, проволока.

То есть разбор прайсов — это ещё и инструмент поиска дыр в номенклатуре.
Заводить позицию по мере надобности, а не все пять тысяч заранее.

## Чего ещё нет

- метизы и лакокрасочные материалы — там номенклатура менее регулярная;
- цена, единица измерения и минимальная партия из строки прайса;
- разбор самого файла (xlsx, pdf, таблица в теле письма) — это отдельный слой
  выше разборщика названий;
- запоминание подтверждённых соответствий за поставщиком.


## Нужен ли здесь локальный ИИ

Вопрос проверен на тех же 437 живых строках. Считалось не «умеет ли модель
разбирать текст», а другое: **есть ли в строке информация, которую вообще
можно извлечь**. Если её нет, не поможет никакая модель, сколько её ни ставь.

| | строк | доля |
|---|---|---|
| правила справились | 311 | 71,2% |
| **позиции нет в нашем справочнике** — сопоставить не с чем, но модель поможет ЗАВЕСТИ | 78 | 17,8% |
| **данных в строке не хватает** — не поможет ничто | 29 | 6,6% |
| заголовок раздела, размера нет вовсе | 9 | 2,1% |
| не прокат (фитинги), отброшено верно | 2 | 0,5% |
| **информация есть, правила не взяли** — вот тут модель нужна | 8 | 1,8% |

**Вывод: на разборе прайсов локальная модель добавит не больше двух процентов.**
И даже этот остаток дешевле закрыть правилом. Пример из той же выборки:
«Арматура 10мм» не разбиралась, потому что между «10» и «мм» нет границы слова.
Это одна строка кода, а не нейросеть.

«Данных не хватает» — это швеллер без указания серии полок: «Швеллер 14»,
«Швеллер 16». У нас 14П, 14У, 14Э и 14Л — разные позиции. Поставщик написал
только номер, и восстановить недостающее нельзя ниоткуда: нужен либо вопрос
поставщику, либо правило по умолчанию.

**Где модель действительно нужна — другое.** 17,8% живых позиций у нас в
справочнике нет вовсе. Сопоставлять не с чем, зато есть что заводить: модель
читает описание поставщика, раскладывает по полям и предлагает черновик
карточки. Плюс три вида отсутствуют целиком — полоса, катанка, проволока.

С одной оговоркой, которая важнее самой модели: **числа модель предлагать не
должна**. Масса погонного метра, шаг резьбы, размеры по ГОСТ — небольшая
локальная модель выдаст их уверенно и иногда неверно, а отличить выдуманное
от верного нельзя. Неверная масса уезжает в КП и в цех. Числа берутся из
строки поставщика или из таблицы ГОСТ, модель только раскладывает текст.
